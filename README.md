# Tutorial: Harmonic Programmed PWM (HPPWM) - Day 1

This repository contains the practical material for the first day of the tutorial,
focused on the numerical resolution of the HPPWM problem and the generation of
the dataset required for neural network training in Day 2.

The objective is to implement a hybrid optimization strategy that combines
global metaheuristic search with local gradient-based refinement to efficiently
compute switching angle solutions for Selective Harmonic Control PWM (SHC-PWM).

## Repository Structure

Each directory contains a base script (`_base.py`) for in-class work,
a complete solution script (`_solution.py`), and a local instructions file.

* **Exercise 1 (Local Solver):** Implementation of a Cartesian cost function
  and configuration of the SQP solver (SLSQP) from SciPy. Demonstrates the
  critical dependence on the initial guess through two scenarios.
* **Exercise 2 (Global Solver):** Implementation of the Differential Evolution
  algorithm with pre-conditioned population. Demonstrates autonomous convergence
  without an initial guess, at the cost of high computational time.
* **Exercise 3 (Hybrid Solver HDE-SQP):** Implementation of the true Hybrid
  Differential Evolution, injecting SQP as a refinement operator inside the
  evolutionary loop. Requires modifying the SciPy source code.
* **Exercise 4 (Dataset Generation):** Automated orchestrator that sweeps a
  2D grid of harmonic references using homotopy continuation, generating the
  10,000-point dataset required for Day 2.

## Dataset Output

The dataset generated by Exercise 4 is saved as `dataset_shcpwm_10000.csv`
in the `data/` folder at the root of the Day 1 directory. It contains:

**Inputs:**
- `m1`, `m5`, `m7`, `m11`, `m13`, `m17`, `m19` — harmonic magnitudes
- `phi5` — phase reference for the 5th harmonic

**Outputs:**
- alpha_1 to `alpha_17` — optimal switching angles (radians)

## Requirements

Python 3.9+ is required. Install dependencies with:

```bash
pip install -r requirements.txt
```

## Important Note on Exercise 3

Exercise 3 requires modifying the SciPy library installed in your Python
environment. Carefully follow the instructions in `exercise_3/exc_3.md`
before running the script. It is recommended to use a virtual environment
to avoid affecting other projects.
