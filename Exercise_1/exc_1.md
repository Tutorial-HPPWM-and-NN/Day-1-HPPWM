# Exercise 1: Local Solver (SQP) and Initial Guess Dependence

## Objective

Implement the Cartesian cost function for the SHE-PWM problem and configure
the SQP solver (SLSQP) from SciPy to find the switching angles for a
17-angle, 7-harmonic problem. The exercise demonstrates empirically how
the choice of initial guess determines whether the solver converges to the
global optimum or becomes trapped in a local minimum.

## Problem Setup

- **N = 17** switching angles using Half-Wave Symmetry (HWS).
- **Harmonics:** h = {1, 5, 7, 11, 13, 17, 19}.
- **Target:** m₁ = 0.85 (fundamental), all other harmonics eliminated.
- **Formulation:** Cartesian domain to avoid atan2 discontinuities.

## Instructions

Open `exercise_1_base.py` and complete the following tasks.

### Task 1: Cartesian Cost Function

Locate the `cost_function`. For each harmonic h:

1. Project the polar reference (m_ref, phi_ref) to Cartesian coordinates:
   - `a_ref = (m_ref / 2) * cos(phi_ref)`
   - `b_ref = (m_ref / 2) * sin(phi_ref)`
2. Compute the squared Euclidean distance between the computed and reference
   Fourier coefficients.

### Task 2: Configure the SQP Solver

Locate `run_sqp_solver` and call `scipy.optimize.minimize`:
- Method: `'SLSQP'`
- Bounds: provided in the function (angles must stay within (0, π))
- Tolerance: `tol=1e-5`

### Task 3: Run Both Scenarios

In the `__main__` block, call `run_sqp_solver` twice:
- **Scenario A:** using `x0_good` (informed initial guess from offline data).
- **Scenario B:** using `x0_bad` (angles clustered in the first quarter).

## Analysis

Observe the console output carefully:

1. Both scenarios report `Success Flag: True`. Why does a "successful"
   run not guarantee a valid solution?
2. Compare the `Iterations` count. Which scenario requires fewer steps?
3. Compare the `Final Error`. Notice that Scenario B reports a high error
   despite the success flag — this is the local minimum trap.
